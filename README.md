# Creativia — Distribuciones

Repositorio de **distribución** de Creativia. Aquí se publican los **ejecutables**
(instaladores y builds) y los **manuales de uso**. El código fuente es privado y
no vive en este repositorio.

## Contenido

- **Releases**: instaladores y ejecutables por versión (pestaña *Releases*).
- **`manuales/`**: manuales de uso (se añadirán con las primeras builds).
